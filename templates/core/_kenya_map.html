{% comment %} Usage: {% include "core/_kenya_map.html" %} (from core/_coverage.html) County shapes come from the geoBoundaries gbOpen KEN ADM1 set, projected to SVG on an equirectangular grid with a cos(lat) correction and simplified to 0.75px. All 47 counties are drawn so the served ones read as part of a country rather than loose shapes; the 19 we work in carry ken-map-served plus a clickable ken-map-dot that drives the live site simulation in _coverage.html. The second panel is a window onto the metro cluster with its neighbours drawn for context, because Kajiado dwarfs the other three and a fit-to-bounds frame reduces Nairobi to a speck. This file is the source of truth; tools/build_kenya_map.py regenerates this panel from a fresh ADM1 download, so run that rather than editing path data by hand if the county list changes. {% endcomment %}
